ChannelLingo 1.4 — bilingual HTML user guide

1. Upload index.html, ar.html, en.html, style.css, app.js, .nojekyll, and the assets folder to a GitHub repository or docs folder.
2. In the repository, open Settings > Pages, choose Deploy from a branch, select main and the folder containing index.html, and save.
3. Once GitHub Pages has published the site, use the resulting website URL to create your QR code.
4. Do not use a guessed URL for the QR code before verifying the published page.

Arabic and English pages keep their content and screenshots from the supplied Word manuals.
